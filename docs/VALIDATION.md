# 검증 결과

## 게스트 체험 · 2026-11-10

게스트별 독립 USER 계정을 만들고 24시간 후 개인 API 접근을 401로 차단한다. 만료 계정과 종속 기록은 매시간 정리한다. PostgreSQL 통합 테스트 2개에서 CSRF·격리·만료·정리·생성 속도 제한을 검증했고, 전체 API 테스트와 bootJar가 통과했다. 웹 타입 검사·린트·단위 테스트 10개·PWA 빌드와 게스트 입장·탐색·로그아웃 브라우저 mock 테스트 1개가 통과했다. 실제 Supabase에서 Flyway V7 적용, API·웹 healthcheck 성공을 확인했다. 실제 게스트 세션으로 오늘·성장·가계부·투자 API가 200, 로그아웃 204, 이후 비로그인 가계부 API가 401임을 확인했다. 브라우저의 실제 API 쓰기 흐름과 실기기 설치는 검증하지 않았다.

## 성장·가계부·투자 · 2026-11-10

API 통합 테스트 28개(Testcontainers PostgreSQL)와 bootJar, 웹 타입 검사·린트·단위 테스트 10개·PWA 빌드가 통과했다. 브라우저 mock 32개는 성장 6개·가계부 5개·투자 4개와 기존 인증·계획·관리자 시나리오를 포함한다. 가계부 만료 세션 fixture를 실제 서버 동작에 맞게 수정한 뒤 해당 시나리오가 통과했다. 2026-11-10 로컬 웹·API 이미지를 교체하고 Supabase 연결에서 Flyway V4–V6가 성공했으며 컨테이너 healthcheck도 통과했다. 실제 관리자 세션으로 `/growth`·`/money`·`/invest`를 읽어 응답 구조를 확인했다. 비로그인 `/money` API는 401, 세 화면 경로는 200이다. 실제 API에 테스트 기록을 쓰는 브라우저 시나리오는 아직 실행하지 않았다.

외부 실시간 시세·주문, OCR, 오늘 홈 성장·금융 집계, 공개 배포와 실기기 설치는 이 단계에 포함하지 않았다. 아래 Phase 0–1과 관리자 기록은 각 당시의 검증 상태를 보존한 것이다.

### 제한

- OCR와 공개 가입용 이메일 검증/복구, 외부 시세·주문, 반복 일정·외부 캘린더 동기화는 구현하지 않았다.
- 실제 iPhone Safari·Android 기기의 설치·키보드·터치, 운영 HTTPS, 원격 GitHub CI는 이번에 검증하지 않았다.
- 목록의 오프셋 커서는 다른 기기의 삭제 중 위치가 바뀔 수 있다. 새로고침으로 다시 조회할 수 있으며 정책은 ADR 0002에 기록했다.
- 소프트 삭제 데이터는 보존하지만 복원 화면은 없다. 세션·로그인 속도 제한은 기존과 같이 단일 API 프로세스 메모리다.
- Docker `npm ci` 전체 의존성 자동 감사는 낮음 2개·중간 11개를 보고했다. 배포 의존성 별도 감사는 0개다. 강제 의존성 변경은 하지 않았으며 아래 Phase 0의 감사 수치는 과거 기록이다.

## 제한과 후속 확인

- iPhone Safari/Android 실기기 설치, 실제 HTTPS 인증서 발급, GitHub 원격 CI는 미검증이다.
