# ADR 0002: Phase 1의 시간·수정·목록 정책

2026-11-07 · 채택

MASTER_SPEC 22장 순서에 따라 기존 Phase 0에 오늘·할 일·내부 일정을 추가한다. 새 라이브러리 없이 기존 JdbcClient·서버 세션·Quasar를 사용한다. 반복 일정·외부 연동·실제 활동·금융은 해당 후속 단계에서 구현한다.

- 수정·삭제는 요청 버전과 현재 버전을 비교하고 트랜잭션 내 행 잠금으로 확인과 쓰기를 보호한다. 오래된 요청은 409이며 사용자 입력을 자동 덮어쓰지 않는다. 완료 재요청은 같은 상태와 직전 버전까지 멱등 처리하며 실제 활동을 만들지 않는다.
- 종일 일정은 `LocalDate` 범위의 종료일 제외 정책, 시각 일정과 시각 마감은 `timestamptz`로 구분한다. 조회는 프로필 시간대, 편집은 일정의 원래 시간대를 사용한다. DST로 존재하지 않는 입력 시각은 거부하고 두 번 발생하는 입력 시각은 먼저 발생한 시각을 선택해 화면에 안내한다.
- Flyway V2는 기존 인증 테이블을 변경하지 않고 소유자·제약·색인을 포함한 테이블만 추가한다. 삭제는 `deleted_at`으로 보존하며 복원 UI와 정리 기한은 추후 결정한다.
- 목록은 생성시각·ID 순, 한 페이지 최대 100건과 추가 불러오기를 제공한다. 현재 오프셋 커서는 다른 기기의 삭제 중 위치가 바뀔 수 있다. 장시간 탐색의 일관성이 요구되면 keyset 커서로 전환한다. 홈의 개수는 전체 집계, 목록은 최대 100건과 전체 화면 링크를 제공한다.

수용 기준과 실행 검증은 [구현 범위](../IMPLEMENTATION.md), [검증 결과](../VALIDATION.md)에 기록한다.
